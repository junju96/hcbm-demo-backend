# zenoh_py 函数接入文档

这个文档用来说明如何在你的程序中使用zenoh的订阅发布.

在python中使用这个, 如果看不明白, 就叫你的ai看这个文档就行了.

但为了后续维护, 建议了解一下使用了什么函数以防出现问题.

版本: 0.2.0.260324
维护人: 张工
更新内容: 当没有router时, 进入内联模式, 方便调试.

## 1. 快速开始和环境准备

这段程序可以让你快速尝试zenoh的发布订阅功能, 在此之前, 现在你的环境中安装zenoh的python包.

```bash
pip install eclipse-zenoh
```

```python
from zenoh_service import (
    close_zenoh,
    get_last_error,
    initialize,
    subscribe_topic,
)

def my_handler(message: dict) -> None:
    print("收到消息:", message["topic"], message["payload_text"])

if not initialize(auto_subscribe_defaults=True):
    raise RuntimeError(get_last_error())

if not subscribe_topic("op/**", buffer_size=200, on_message=my_handler):
    raise RuntimeError(get_last_error())
```

## 2. 推荐接入流程

1. 调用 `initialize()` 建立 zenoh 会话。
2. 使用 `subscribe_topic(topic, on_message=你的函数)` 订阅并注册回调。
3. 在你的回调函数内编写业务逻辑（过滤、转换、入库、转发）。
4. 使用 `publish_topic()` 主动发布消息（可选）。
5. 如果当前没有启动 router，模块会自动退回到“本地 peer 测试模式”，这样同一进程内 `publish_topic()` 发出的消息仍然可以被本进程 `subscribe_topic()` 收到。
6. 程序退出时调用 `close_zenoh()` 释放资源。

## 3. 对外函数总览

### `initialize(auto_subscribe_defaults: bool = True) -> bool`

- 作用：初始化客户端与会话。
- 返回：成功为 `True`，失败为 `False`。
- 失败原因：通过 `get_last_error()` 获取。

### `subscribe_topic(topic: str, buffer_size: int | None = None, on_message: callable | None = None) -> bool`

- 作用：订阅主题并可绑定消息回调。
- 参数：
  - `topic`：订阅表达式，例如 `op/**`。
  - `buffer_size`：本主题的缓存大小，默认使用内部默认值。
  - `on_message`：消息回调函数，签名 `func(message: dict) -> None`。
- 返回：成功为 `True`。

### `stop_subscribe(topic: str) -> bool`

- 作用：取消某个主题订阅。
- 返回：成功为 `True`。

### `publish_topic(topic: str, payload: Any) -> bool`

- 作用：发布消息到指定主题。
- `payload` 支持：`bytes`、`dict`、`list`、`str`、`int`、`float`、`bool`、`None`。
- 当无法建立到 Zenoh router 的正常会话时，如果允许本地回退，消息会在当前进程内按订阅表达式直接分发，方便单机测试。
- 返回：成功为 `True`。

### `poll_topic(topic: str, limit: int = 50) -> list[dict]`

- 作用：从本地缓存拉取指定主题最近消息。
- 返回：消息列表，按最近顺序截取。

### `recent_messages(topic: str, limit: int = 20) -> list[dict]`

- 作用：`poll_topic` 的别名，语义更偏“最近消息”。

### `list_subscriptions() -> list[str]`

- 作用：查看当前已订阅主题列表。

### `subscribe_default_topics() -> bool`

- 作用：按 `zenoh_service.json` 中 `default_subscriptions` 自动订阅。

### `get_default_subscriptions() -> list[dict]`

- 作用：读取并返回默认订阅配置。

### `health() -> bool`

- 作用：检查会话是否可用。

### `get_last_error() -> str`

- 作用：获取最近一次失败原因。

### `close_zenoh() -> bool`

- 作用：关闭会话并释放订阅/发布资源。

## 4. 如何插入你的函数

最常见方式是把你的函数作为 `on_message` 回调传入。

```python
from zenoh_service import subscribe_topic

def my_business_logic(message: dict) -> None:
    topic = message.get("topic", "")
    payload = message.get("payload_text", "")
    if topic.startswith("op/t01/"):
        process(payload)

def process(payload: str) -> None:
    print("处理后的结果:", payload)

subscribe_topic("op/**", on_message=my_business_logic)
```

## 5. 回调 message 字段说明

回调收到的 `message` 是一个 `dict`，常用字段：

- `topic`: 主题字符串。
- `timestamp`: UTC 时间戳（ISO 格式）。
- `payload_text`: UTF-8 可解码的文本载荷。
- `payload_base64`: 二进制载荷时的 Base64 字符串，否则为 `None`。
- `is_binary`: 是否为二进制载荷。

## 6. 常见失败处理模板

```python
from zenoh_service import get_last_error, initialize, subscribe_topic

if not initialize():
    print("initialize failed:", get_last_error())

if not subscribe_topic("op/**"):
    print("subscribe failed:", get_last_error())
```

## 7. 无 router 的本地 peer 测试

如果你只是想在一个 Python 进程里做“发一个主题，再收这个主题”的测试，不想额外启动 router，可以直接这样写：

```python
from zenoh_service import (
    get_last_error,
    initialize,
    poll_topic,
    publish_topic,
    subscribe_topic,
)

if not initialize(auto_subscribe_defaults=False):
    raise RuntimeError(get_last_error())

if not subscribe_topic("demo/topic"):
    raise RuntimeError(get_last_error())

if not publish_topic("demo/topic", {"msg": "hello"}):
    raise RuntimeError(get_last_error())

print(poll_topic("demo/topic", limit=10))
```

说明：

- 如果 router 可用，优先走正常 Zenoh 会话。
- 如果 router 不可用，并且 `zenoh_service.json` 里的 `local_peer_fallback` 为 `true`，则自动切换到“本地 peer 测试模式”。
- 这个模式只保证当前进程内的发布/订阅联调，不等价于跨进程、跨机器的真实 Zenoh 互联。

## 8. 配置文件位置

- zenoh 配置默认文件：`zenoh.json5`
- 服务配置默认文件：`zenoh_service.json`
- 两者默认都从 `zenoh_py` 当前目录读取。
- 也可通过环境变量覆盖：
  - `ZENOH_CONFIG_PATH`
  - `ZENOH_SERVICE_CONFIG_PATH`
  - `ZENOH_CONFIG_JSON5`
  - `ZENOH_SERVICE_CONFIG_JSON`
- `zenoh_service.json` 还支持：
  - `local_peer_fallback: true`：允许在 router 不可用时自动退回本地测试模式
  - `local_peer_fallback: false`：禁用回退，保持严格依赖 router 的行为

示例：

```json
{
  "local_peer_fallback": true,
  "default_subscriptions": []
}
```
